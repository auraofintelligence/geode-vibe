An interactive, single-page concept that explains a proposed security architecture for Aura of Intelligence and the physical Aura Geode idea.

**Public concept page:** <https://auraofintelligence.github.io/geode-vibe/>

## What the page explores

- personal, clinical and technical trust
- an interactive threat-surface model
- a proposed sovereignty stack
- safeguards for LLMs, autonomous agents and component provenance
- different ways to communicate the architecture to technical and non-technical audiences

Open `index.html` in a browser. There is no build step; the page loads Tailwind CSS and web fonts from external services.

## Status and boundaries

This is an architecture explainer, not an implemented security system, audited product, medical device, clinical study, regulatory submission or compliance guarantee. Statements about encryption, federated learning, identity, ledgers, consent and hardware roots of trust describe the proposed model and still require engineering, threat modelling, testing, governance and independent review.
